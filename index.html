About Me

Engineering discipline meets
renewable energy mission

I am a DevOps & Platform Engineer operating a shared, multi-tenant EKS environment managed end-to-end via Infrastructure as Code. I own the full platform lifecycle — from cluster provisioning to observability to compliance evidence — with zero console/ClickOps drift.

I design and operate EKS Kubernetes clusters following GitOps principles with Argo CD, managing all cloud and platform resources — including observability — via IaC. DevSecOps controls are embedded directly into CI/CD pipelines so security and compliance are default, not afterthoughts.

Built and operated a production AWS platform — a shared multi-tenant EKS environment — provisioned via Terraform/Terragrunt and delivered through ArgoCD GitOps. Workloads promote across dev → staging → prod, with audit-ready evidence from Git history, IaC modules, and monitoring dashboards.

Strong background in Linux, Windows, and AWS infrastructure across both production environments and experimental local labs, following Infrastructure as Code and Observability as Code principles throughout. Applying AWS Well-Architected Framework best practices across all workloads. Authored platform runbooks, onboarding docs, and best-practice guides for developers and SREs.

Currently pursuing AWS Solutions Architect Associate and CKA (Certified Kubernetes Administrator) — actively studying and building labs daily to deepen cloud-native and Kubernetes expertise.
